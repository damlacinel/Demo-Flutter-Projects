# Demo Project 3) Expense Tracker
This repository consists of different demo projects, that reflects my Flutter/Dart learning process. This project is the third demo project of this series.

The application consists of a list of expenses, which can be added by the user through input page. This input page takes a title, amount and category of the soon to be added expense. All expenses are shown using a chart in the main page, this way the user can track which category has the highest or lowest expense.
